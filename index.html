01 / The simple starting point

Pocket TTS

Kyutai’s voice-cloning model runs on CPU, so you can start without a dedicated GPU. Give it a clean voice sample and the words you want spoken. A good first choice for a local setup.

↗ GitHub & setup↗ Try the demo
QUICK START · REQUIRES UV
uvx pocket-tts generate --voice ./reference.wav \
  --text "I tried this for a week. Here is what actually changed." \
  --output-path ./voiceover.wav

The first run downloads the model. Use the agent prompt below if you want it to handle installation and hardware settings.

02 / More voice options

Chatterbox

Resemble AI’s TTS family also clones voices from reference audio. Turbo supports expressive cues like laughter; the Multilingual model covers more languages. Choose the variant for your hardware—Turbo’s official example uses an NVIDIA GPU.

03 / Copy, paste, build

Give this to your coding agent

Have a clean, single-speaker recording ready—around 10 seconds is a practical starting point—and your finished script. Use your own voice or one you have permission to clone.

AGENT PROMPT
Set up local voice cloning for my AI UGC voiceovers.

Read the current official docs first:
https://github.com/kyutai-labs/pocket-tts
https://github.com/resemble-ai/chatterbox

Check my OS, Python version and GPU. Start with Pocket TTS for a simple CPU setup; offer Chatterbox if I want more expression or language options. Use a separate Python environment and install dependencies for my hardware.

I will provide reference.wav (my voice or a voice I have permission to use) and script.txt. Generate voiceover.wav from that script using the reference voice. Start with one short test, let me listen, then generate the full script in manageable chunks.

Give me a repeatable command and a minimal local UI to upload a reference, enter text, preview and download WAV. Keep files local, bind the UI to localhost, handle missing files clearly, and document the installed versions. If model access needs approval or a login, tell me before proceeding.

No ElevenLabs subscription required. You still need compute, storage and the initial model download. Voice quality depends on your sample and chosen model; listen to a short test before rendering everything.
